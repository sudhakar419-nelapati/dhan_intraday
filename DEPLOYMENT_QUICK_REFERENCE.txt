"API Connection FAILED"
→ Go to: Settings → Secrets
→ Check both credentials are there
→ Save again, wait 30 seconds
→ Refresh dashboard

"Module not found" or "Import error"
→ Make sure everything is pushed to GitHub
→ Check all files are present
→ Verify requirements.txt has all packages

"No live data"
→ Check time (09:15-15:30 IST only)
→ Outside these hours, data may be empty
→ Next trading day during market hours

"App still loading"
→ Refresh page (Ctrl+R)
→ Wait 1-2 minutes
→ Check Settings → Logs for errors
→ Clear browser cache
