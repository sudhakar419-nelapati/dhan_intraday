================================================================================
                             HOW TO START DASHBOARD
================================================================================

STEP 1: Start the Streamlit Application
--------
Run this command in your terminal:

    cd C:\Users\ADMIN\IdeaProjects\dhan_intraday
    streamlit run dashboard.py

STEP 2: Dashboard Opens Automatically
--------
Streamlit will:
  1. Launch your default web browser
  2. Open the app at: http://localhost:8501
  3. Show the STAR Trading Scanner interface

STEP 3: Explore the Dashboard
--------
The dashboard has 5 tabs:

  [Tab 1: Overview]
    - Displays scanner readiness status
    - Shows current market time and session status
    - Displays universe configuration
    - Shows universe statistics

  [Tab 2: Live Scanner]
    - Fetches live futures data for each symbol
    - Calculates all 8 STAR gates
    - Shows readiness percentage (0-100%)
    - Displays live recommendations:
      * Full Quantity (8/8 gates pass)
      * Half Quantity (6-7/8 gates pass)
      * Wait (4-5/8 gates pass)
      * Stay Out (<4/8 gates pass)

  [Tab 3: Gate Details]
    - Detailed breakdown of each gate result
    - Gate 1-6: Options chain analysis (formulas customizable)
    - Gate 7: Futures read (Fresh/Covering/Short/Unwinding)
    - Gate 8: Neutralization status (session accumulation)
    - Shows pass/fail criteria for each gate

  [Tab 4: Session History]
    - View all past scanner results
    - See historical signal tracking
    - Track cumulative session state
    - Audit trail of changes

  [Tab 5: API Test]
    - Test connection to DHAN API
    - Fetch sample futures candles
    - Fetch options chain data
    - Verify live data availability

================================================================================
                              TROUBLESHOOTING
================================================================================

If Streamlit doesn't open automatically:
  1. Open browser manually
  2. Navigate to: http://localhost:8501

If you see "API Connection FAILED":
  1. Verify DHAN_API_KEY in .env file
  2. Verify DHAN_CLIENT_ID in .env file
  3. Check internet connection
  4. Verify API endpoint format for your DHAN account
  5. Check if market is open (live data only during trading hours)

If database errors occur:
  1. Ensure ./data/ directory is writable
  2. Check ./logs/ for detailed error messages
  3. Delete ./data/scanner.db to reset database

If performance is slow:
  1. Reduce MAX_CONCURRENT_SYMBOLS in .env (default: 5)
  2. Increase API_TIMEOUT_SECONDS in .env (default: 10)
  3. Check internet bandwidth availability
