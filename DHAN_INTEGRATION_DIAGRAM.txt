║                     TROUBLESHOOTING QUICK REFERENCE                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ "API Connection: FAILED"
   → Check DHAN_API_KEY in .env
   → Check DHAN_CLIENT_ID in .env
   → Verify no spaces/typos
   → Check internet connectivity

❌ "No data returned"
   → Market closed? (Test 09:15-15:30 IST, Mon-Fri)
   → Wrong symbol? (Must be NSE F&O, e.g., RELIANCE)
   → Wrong expiry? (Must be existing, e.g., 27NOV2026)

❌ "Module not found"
   → Run: pip install -r requirements.txt
   → Run: python test_api.py

❌ Streamlit won't open
   → Run: streamlit run dashboard.py --server.port=8501
   → Open browser to: http://localhost:8501


For more help, see: DHAN_API_QUICK_START.md or API_SETUP_GUIDE.md
